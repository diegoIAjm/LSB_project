👨‍🏫 Importar Docentes

Importe docentes masivamente desde un archivo Excel

📋 Instrucciones

  • El archivo debe ser formato .xlsx o .xls
  • Las columnas deben estar en este orden: Nombre, Apellido, Email, CI, Especialidad
  • La contraseña se asignará automáticamente con el CI
  • El rol se asignará automáticamente como Docente
  • El estado será Activo por defecto

📝 Ejemplo de formato Excel

NombreApellidoEmailCIEspecialidad
{{ celda }}
